# Alpha Internal Console

The Alpha Internal Console is an internal administrative tool used only by
Tenant Alpha's own operations staff. It depends on the Alpha Console
Database for storing session and configuration state. Access is restricted
to Tenant Alpha operators; no other tenant may view or reference this
system.
