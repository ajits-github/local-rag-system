    Vision¶

    base ¶

    Vision provider: image/diagram understanding for image-derived indexable content.

    config.vision.provider/factory.build_vision_provider wire this ABC in, but the only provider implemented so far is "none": text-only image handling (alt text/caption) needs no VisionProvider at all. No hosted-API-calling concrete subclass exists yet. Tests use a local mock subclass, never a class capable of a real network call.

    VisionProvider ¶

    Bases: ABC

    Describes an image file in natural language, for ingestion as chunk text.

    provider_name abstractmethod property ¶

    provider_name: str

    Short identifier for this provider (e.g. "openai"), for cache/provenance records.

    model_name abstractmethod property ¶

    model_name: str

    The specific model used, for cache/provenance records.

    prompt_version abstractmethod property ¶

    prompt_version: str

    Identifier for the instruction prompt this provider sends with each image.

    Part of the image-description cache key alongside provider_name/ model_name (see ingestion.writer.Writer._with_vision_siblings), so editing the prompt text invalidates cached descriptions the same way switching provider/model does, rather than silently serving descriptions generated under different instructions.

    describe_image abstractmethod ¶

    describe_image(
    image_path: Path, alt_text: str | None = None
) -> str

    Produce a text description of image_path.

    Parameters:

    Name Type Description Default
    image_path Path

    Path to the image/diagram file.

    		 required
    alt_text str | None

    Author-supplied alt text/caption, if any, used as grounding context rather than replaced outright, by default None.

    		 None

    Returns:

    Type Description
    str

    A natural-language description suitable for embedding as chunk content. Implementations must not fabricate specifics (colors, counts, unlabeled relationships) they cannot verify. Callers store this separately and never overwrite the image's original caption or alt text.

    OllamaVisionProvider ¶

    OllamaVisionProvider(
    model_name: str = "moondream",
    base_url: str = "http://localhost:11434",
    prompt_version: str = _PROMPT_VERSION,
)

    Bases: VisionProvider

    Describes an image via a local Ollama vision model (e.g. moondream).

    Offline by construction: ollama.Client talks to a native-host Ollama server (same one OllamaLLM uses for generation), never a hosted API, so config.security.egress_policy is never involved for this provider -- see config.VisionConfig's docstring.

    Construct the Ollama client used for vision calls.

    Parameters:

    Name Type Description Default
    model_name str

    Ollama vision-model tag, by default "moondream". Must be pulled locally (ollama pull moondream) before use -- never installed automatically.

    		 'moondream'
    base_url str

    Ollama server URL, by default "http://localhost:11434".

    		 'http://localhost:11434'
    prompt_version str

    Identifier for the instruction prompt this provider sends, by default _PROMPT_VERSION. Exposed as a constructor parameter (rather than hardcoded) only so tests can pin a distinct value; production callers should leave it at the default, which tracks this module's actual _PROMPT text.

    		 _PROMPT_VERSION
