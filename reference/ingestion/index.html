    Ingestion¶

    pipeline ¶

    Explicit ingestion pipeline: loader -> cleaner -> chunker -> embedder -> writer.

    Also runnable as a CLI: python -m rag.ingestion.pipeline <path> --dataset-id <id> (used by make ingest FILE=... DATASET_ID=...).

    IngestionPipeline ¶

    embedder: Embedder | None = None,
    vision_provider: VisionProvider | None = None,
)

    Runs a document through loader -> cleaner -> chunker -> embedder -> writer.

    Wire up the pipeline's stages from config (or injected instances).

    Parameters:

    Name Type Description Default

    Application configuration.

    		 required
    vectorstore VectorStore | None

    Vector store to write to; built from config if omitted.

    ingest_file ¶

    ingest_file(
    path: Path, dataset_id: str, category: str | None = None
) -> dict[str, Any]

    Load, clean, chunk, embed, and persist a single file.

    Skips re-writing chunks if the file's checksum is unchanged since the last ingestion of the same (source, dataset_id).

    Parameters:

    Name Type Description Default
    path Path

    File to ingest.

    		 required
    dataset_id str

    Namespace tag stored on every chunk.

    		 required
    category str | None

    Folder-derived category tag, by default None.

    		 None

    Returns:

    Type Description
    dict[str, Any]

    {"document_id", "chunks_written", "changed"}.

    Raises:

    Type Description
    ValueError

    If path's extension isn't in config.ingestion.supported_extensions.

    ingest_path ¶

    ingest_path(path: Path, dataset_id: str) -> IngestionStats

    Ingest a single file, or recursively ingest a directory tree.

    Every chunk written is tagged with dataset_id, isolating it from every other dataset at retrieval time. When walking a directory, each file's path relative to path is additionally recorded as the chunk metadata's category.

    For a directory target, also detects documents deleted since the last ingestion (diffing the pre-run set of known sources against what's discovered this run) and deletes them via delete_documents_by_source. Skipped for a single-file target.

    Parameters:

    Name Type Description Default
    path Path

    A single file, or a directory to walk recursively.

    		 required
    dataset_id str

    Namespace tag stored on every chunk.

    		 required

    Returns:

    Type Description
    IngestionStats

    Aggregate counts plus one ingest_file-shaped entry (with an added "status" key: "new"/"changed"/"unchanged") per file processed, in .results.

    main() -> None

    CLI entrypoint: parse args and run IngestionPipeline.ingest_path.

    writer ¶

    Ingestion stage 5: embed chunk texts and persist them to the vector store.

    Writer ¶

    Writer(
    embedder: Embedder,
    vectorstore: VectorStore,
    vision_provider: VisionProvider | None = None,
)

    Embeds chunk texts and persists them to the vector store.

    Store the embedder/vectorstore/vision provider this writer will use.

    Parameters:

    Name Type Description Default
    embedder Embedder

    Embedder used to vectorize chunk texts.

    		 required
    vectorstore VectorStore

    Vector store the resulting chunks are persisted to.

    		 required
    vision_provider VisionProvider | None

    When set, a vision-generated sibling chunk is added for every image span (see _with_vision_siblings). None (the default, and the only mode exercised so far) means text-only image handling. No image bytes are ever read, no network call is possible.

    		 None

    vision_provider property ¶

    vision_provider: VisionProvider | None

    The configured VisionProvider, or None for text-only image handling.
